# 让 OH2P 小爱音箱用上小智

对音箱说 **“你好小智”**，就能开始聊天。支持连续问答、播报时插话，以及开始和结束提示音。音箱使用原有的回声消除，增强音频中断时会自动尝试恢复。

**直接下载现成安装包即可，不需要编译代码，也不需要安装 Python。** 每个人安装后绑定自己的小智账号。

## 这套版本主要改进了什么？

这套程序基于 [Open-XiaoAI 的小智示例](https://github.com/idootop/open-xiaoai/tree/main/examples/xiaozhi) 修改。接入小智、账号绑定、自定义唤醒词和连续对话都是上游已有的能力。我们主要针对 **OH2P 的采音、插话和日常使用**做了这些改进：

- **它在说，你也能直接插话。** 回答期间继续接收你的声音，检测到你开口后，停止当前播放并通知小智中止回答，不必专门再喊一次“小爱同学”。同时清掉音箱里还没播出的音频，避免打断后旧回答继续往外播。
- **把 OH2P 原有的回声消除接给小智。** 使用音箱原厂处理后的增强音频，让小智在音箱播放时也能接收你的讲话。AEC 是音箱原有的能力，本项目做的是接入和配套控制，不是重新发明一套回声消除算法。
- **补上了一种“程序还在，采音却停了”的恢复处理。** 原始音频仍在到达、但增强音频连续约 5 秒没有输出时，程序会尝试重新开启增强输出；未恢复时隔至少 30 秒再试。这针对的是已遇到的一类断流问题，不代表所有故障都能自动恢复。
- **开始和结束都有提示音。** 听到开始提示音就可以提问；结束提示音提醒你，这轮聊天已结束，下次需要重新唤醒。
- **减少久放后唤醒等待，避免重复启动。** 空闲时发现云端连接已断开，会尝试重新连接；连接失败隔 30 秒再试。正在唤醒或聊天时重复喊唤醒词，不会再启动一轮。连接尚未完成就结束，也不会稍后突然开始聊天。详见[本次更新说明](docs/UPDATE-20261027.md)。
- **准备好了能直接安装的包。** 音箱程序、NAS Docker 镜像和启动文件分别提供下载，照教程安装后绑定自己的小智账号，不需要从源码编译。

上游本来就支持打断；它的小智示例说明的是喊“小爱同学”打断。这里重点补的是播放期间持续采音、普通讲话触发打断，以及 OH2P 增强音频的接入。我们没有做同条件的音质、延迟和长期稳定性对比，不宣称全面优于上游。

**需要一台同一局域网内、持续开机的 NAS 或 Docker 主机。** 音箱负责采音和播放，NAS 负责唤醒检测、插话判断及连接小智云端。这不是脱离网络运行的本地大模型，也不是只装音箱就能使用的版本。

## 第一次安装，从这里开始

先看你的音箱属于哪种情况：

| 你的情况 | 先做什么 |
| --- | --- |
| OH2P **1.62.2，已经能用 SSH 登录** | **不用刷机**，下载下面三个安装包 |
| 没有 SSH，或不清楚固件版本 | 先看[音箱系统准备说明](docs/LIVE-FIRMWARE.md)，准备好后再安装。SSH 就是从电脑登录音箱执行命令的方式 |
| 已经装好并绑定，只想继续使用 | 不用重新安装；保留 NAS 的 `data/config.py`，里面有你的设备绑定信息 |

### ① 先下载这三个文件

三个都要下载，版本统一为 **2026.10.24.1**。NAS 需要是 Intel/AMD 64 位；这里的 Docker 包不适用于 ARM NAS。

| 顺序 | 点击下载 | 下载后怎么处理 |
| --- | --- | --- |
| 1 | [NAS 启动文件：oh2p-xiaozhi-easy-install.zip](https://github.com/ChouMax-1989/oh2p-xiaozhi-aec/releases/download/v2026.10.24.1/oh2p-xiaozhi-easy-install.zip) | 解压到 NAS，得到 `oh2p-xiaozhi` 文件夹 |
| 2 | [NAS Docker 镜像：oh2p-xiaozhi-nas-amd64.tar.gz](https://github.com/ChouMax-1989/oh2p-xiaozhi-aec/releases/download/v2026.10.24.1/oh2p-xiaozhi-nas-amd64.tar.gz) | 不解压，上传到上述文件夹，按教程导入 Docker |
| 3 | [音箱程序：oh2p-xiaozhi-speaker.tar.gz](https://github.com/ChouMax-1989/oh2p-xiaozhi-aec/releases/download/v2026.10.24.1/oh2p-xiaozhi-speaker.tar.gz) | 不解压，先放在电脑上，按教程上传到音箱 |

**普通安装不用下载 `Source code`，也不用下载带 `candidate` 字样的旧候选固件。** 音箱程序包不是刷机文件，Docker 镜像也不能刷到音箱里。

### ② 照教程安装

打开 **[小白安装步骤](docs/DEPLOYMENT.md)**，从第一步顺着做，不用自己编译。NAS 和音箱放在同一局域网，NAS 先安装 Docker 和 Docker Compose。

顺序是：**NAS 导入镜像 → 电脑上传音箱程序并安装 → 启动 NAS 服务 → 重启音箱一次**。教程逐步标明在哪台设备输入命令，以及成功时会看到什么。

### ③ 绑定你自己的小智账号

1. 打开 [xiaozhi.me](https://xiaozhi.me/)，登录，创建或选择智能体，进入设备绑定入口。
2. 对音箱说 **“你好小智”**，把本次生成的验证码填到网站上。没有听到验证码时，按[绑定步骤](docs/DEPLOYMENT.md#第五步绑定自己的小智账号)从 NAS 查看。
3. 绑定后再说“你好小智”并提问。还提示未绑定时，按教程重启 NAS 的 `server` 服务后再试。

验证码不是固定的，不用找作者索取。不要删除或用空白文件覆盖 NAS 的 `data/config.py`，否则可能丢失本机绑定信息。

### 只有需要准备音箱系统时，才看固件

[OH2P 1.62.2 现机脱敏固件：说明与下载](docs/LIVE-FIRMWARE.md)来自实际使用的系统，保留声音和启动配置。**脱敏后的公开包尚未重新刷机验收**；它不是一键安装包，也不是上面三个文件的替代品。不熟悉分区刷写时，先不要刷，已有 SSH 的音箱更不需要为安装小智而重刷。

旧的 `firmware-1.62.2-candidate-20261024` 只保留作历史构建资料，**不用于本教程安装**。更多原厂文件与技术资料放在[固件资料页](docs/FIRMWARE.md)。

## 装好以后

1. 说“你好小智”，听到开始提示音后提问。
2. 可以接着问下一句，也可以在音箱说话时插话。
3. 保持安静约 20 秒，会话结束并播放结束提示音；下次再说唤醒词即可。

配置默认是“你好小智”，没有附带任何人的账号、设备绑定或验证码。第一次使用时，按音箱提示绑定自己的小智账号。

## 使用情况

同源 AEC 路线曾由用户验证过连续对话和打断，增强音频修复后也确认可以唤醒。当前版本的长期稳定性、全新设备安装、首次绑定和整机重启等仍需按[验收清单](docs/VERIFICATION.md)确认。

遇到问题看[排错说明](docs/TROUBLESHOOTING.md)。需要了解实现或自行修改代码，再看[运行原理](docs/ARCHITECTURE.md)、[服务端源码说明](server/README.md)和[音箱端构建说明](edge/BUILD.md)。

项目保留了实际使用的 AEC、连续采音、实时对话、插话、提示音，以及 5 秒增强断流恢复修改。基于 [open-xiaoai](https://github.com/idootop/open-xiaoai) 和 [xiaoai-agent](https://github.com/stevenjoezhang/xiaoai-agent) 的相关实现，许可证见 [NOTICE.md](NOTICE.md)；设备固件中的专有库不随附加安装包分发。
